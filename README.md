# Systems Engineer Portfolio

A responsive portfolio built with React and Vite. Its deep-sea telemetry visual
system presents the profile, experience, projects, technical skills, education,
and contact details.

## Development

```sh
npm install
npm run dev
```

## Checks

```sh
npm run lint
npm run build
```

## Project structure

- `src/components/` contains the page sections and shared navigation/heading
  components.
- `src/data/portfolio.js` holds the profile, experience, project, skill, and
  education content.
- `src/App.css` and `src/index.css` contain the application and global styles.
